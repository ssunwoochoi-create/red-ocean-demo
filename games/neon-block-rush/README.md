# NEON BLOCK RUSH · 네온 블록 러시

8×8 보드에 네온 블록 조각을 끌어다 놓고, 가로·세로 줄을 가득 채워 터뜨리는 아케이드 퍼즐 게임입니다.

**바로 플레이:** https://ssunwoochoi-create.github.io/neon-block-rush/

설치도 로그인도 없습니다. 링크만 열면 폰이나 PC에서 바로 시작됩니다.

## 게임 방법

- 보드 아래에 3개씩 주어지는 블록을 손가락(또는 마우스)으로 끌어다 8×8 보드에 놓습니다.
- 가로 또는 세로 한 줄이 꽉 차면 그 줄이 한꺼번에 터지고 점수가 올라갑니다.
- 연속으로 터뜨리면 `2 COMBO!`, `3 COMBO!`처럼 배수가 붙습니다.
- 한 번에 2줄은 `DOUBLE!`, 3줄은 `TRIPLE!`, 4줄 이상은 `MEGA CLEAR!!`.
- 콤보 게이지가 가득 차면 **FEVER MODE** — 3턴 동안 점수 2배, 보드가 네온으로 빛납니다.
- 🔄 **리롤**: 조각 3개를 새로 뽑습니다. (기본 2회, 5,000점마다 1회 충전)
- 💣 **폭탄**: 보드의 3×3 칸을 없앱니다. (기본 1회, 8,000점마다 1회 충전)
- 더 이상 블록을 놓을 곳이 없으면 게임 오버. 최고 기록은 브라우저(localStorage)에 저장됩니다.

## 만든 방식

- 모바일 터치용 드래그: 손가락 아래가 아니라 **손가락 위쪽(약 56~64px)에 블록이 떠서** 손에 가려지지 않고, 보드에는 반투명 고스트 미리보기와 지워질 줄 하이라이트가 바로 표시됩니다.
- 효과음은 외부 음원 없이 **Web Audio API로 실시간 합성**합니다. 콤보가 쌓일수록 음계가 도→레→미→파→솔→라→시→도 순으로 올라갑니다.
- 줄이 터질 때 네온 파티클 폭발과 미세 화면 흔들림, 점수 플로팅 텍스트가 함께 나옵니다.

## 기술

- 순수 HTML + CSS + JavaScript (Canvas 2D), 외부 라이브러리·빌드 없음
- `index.html` 파일 하나로 완결됩니다. 파일을 내려받아 열어도 그대로 동작합니다.
- 데스크톱 1280×800, 모바일 375×812 화면에서 동작 검수 완료 (콘솔 에러 0건, 60fps)
